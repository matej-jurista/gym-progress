GYM PROGRESS PWA v4

NOVÁ LOGIKA:
- periodizácia má prioritu pred "agresívnym" progresom
- W2–W5: maximálne jeden plánovaný krok za týždeň
- silný tréning nepovolí extra skok navyše
- posledný drop/pump set sa neberie automaticky ako zhoršenie
- ak pracovné série spadnú pod spodnú hranicu reps, progres sa pozastaví
- nový W1 sa odvíja od W1 predchádzajúceho cyklu + malý krok, nie od W5
- odporúčanie sa zobrazuje pre celý cvik aj pre jednotlivé série
- zachované: per-set váhy/reps, minulé hodnoty, dátumy, história, grafy, výmena cvikov, export/import
- appka sa pokúsi načítať existujúce dáta z v3 localStorage

SPUSTENIE PWA:
Musí bežať cez HTTPS alebo localhost.
Lokálne:
  python3 -m http.server 8080
Potom:
  http://localhost:8080
